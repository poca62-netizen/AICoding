# 가까운 학교 찾기

PRD v1.0의 P0를 구현한 Flutter 앱입니다. Android, Windows, 웹 프로젝트를 포함합니다.

## 실행

이 README가 있는 폴더에서 실행하세요.

```powershell
flutter pub get
flutter run -d chrome
```

Android 기기/에뮬레이터에서는 `flutter run`으로 실행합니다. 웹 배포 파일 생성은 `flutter build web --release`입니다. `build/web`은 HTTP 서버로 제공해야 합니다.

## 사용 순서

1. 오른쪽 위 설정에서 본인의 카카오 **REST API 키**를 입력합니다.
2. 집 주소를 검색하고 검색 결과에서 정확한 주소를 선택합니다.
3. 학교 이름만 입력해 검색하고 결과에서 학교·캠퍼스를 선택합니다. 주소를 선택적으로 입력하면 기존 주소 검색을 사용합니다. 여러 학교를 반복해서 추가합니다.
4. **가까운 학교 찾기** 버튼으로 km 단위 직선거리를 비교합니다.
5. 입력 또는 결과 화면에서 학교를 삭제할 수 있습니다. 결과 화면의 삭제는 돌아간 입력 화면에도 반영됩니다.

키 없이 **예시 체험**을 선택하면 가상 학교 3곳과 예시 좌표로 거리 계산을 확인할 수 있습니다. 실제 학교 검색 결과가 아니며, 실제 입력 모드로 돌아가면 예시가 초기화됩니다.

## 카카오 설정

- https://developers.kakao.com/ 에서 앱을 생성하고 REST API 키를 확인합니다.
- 카카오맵 사용 권한/활성화 및 앱에 적용되는 이용 한도를 확인하세요.
- 공식 문서: https://developers.kakao.com/docs/ko/kakaomap/rest-api
- 주소 검색: `GET /v2/local/search/address.json`, 인증: `Authorization: KakaoAK ...`.
- 학교 이름만 입력하면 카카오 일반 키워드 검색(분류 제한 없음, 최대 15곳)을 사용합니다. 결과의 학교명·주소·좌표가 함께 등록됩니다. 주소를 입력한 경우에는 주소 검색을 사용합니다.
- 검색어는 카카오로 전송됩니다. 키와 입력 목록은 디스크에 저장하지 않습니다.
- 개인용 MVP입니다. 웹/앱에 공용 운영 키를 내장하여 배포하지 마세요. 공개 서비스로 확장할 때는 서버 프록시와 접근 제한을 추가하세요.

## 구현 범위

- F1~F6: 출발지 입력, 학교 추가, 주소→좌표 변환, Haversine 직선거리, 오름차순 정렬, 삭제.
- 주소 후보 확인, 빈 입력/중복 학교 방지, 출발지 수정 시 좌표 무효화.
- 검색 중 중복 작업 방지, 잘못된 주소/인증 실패/호출 한도/통신 오류/타임아웃 안내.
- 모바일 1열, 넓은 화면 2열 반응형 UI.
- 지도(P1): 출발지·학교 마커, 학교 선택 이동, 확대/축소, 전체 위치 보기 구현. 도로 거리/시간/저장/대중교통(P2)은 제외.
- 거리 계산은 이미 확정된 좌표로 기기에서 즉시 수행합니다. 외부 검색 응답 3초 및 주소 인식률 90%는 실제 API 키와 주소 표본으로 별도 검증해야 합니다.

## 검증

```powershell
flutter analyze
flutter test
flutter build web --release
```

테스트는 알려진 거리/동일·대척 좌표, 정렬·동률 처리, 카카오 응답과 오류(모의 응답), 예시 사용 흐름과 삭제, 모바일 초기화를 확인합니다. 실제 카카오 API 호출은 본인 키를 입력한 뒤 확인하세요.

## 코드

- `lib/main.dart`: 입력·설정·주소 선택·결과 UI
- `lib/school.dart`: 모델, 거리 계산, 정렬
- `lib/geocoder.dart`: 카카오 API 및 오류 처리
- `test/`: 계산, API, 화면 흐름 테스트

검증 결과: 자동 테스트 11개 통과, dart analyze lib test 이상 없음, 웹 release 빌드 성공. 이 환경의 flutter analyze는 분석 서버 통신 오류로 종료되어 dart analyze lib test로 대체 검증했습니다. Android/Windows 네이티브 빌드는 아직 검증하지 않았습니다.

## 지도 업데이트
지도 배경은 별도 지도 키 없이 OpenStreetMap을 사용합니다. 주소 검색은 카카오 API를 유지합니다. PRD의 카카오 지도 SDK 대신 웹·모바일에서 같은 Flutter 지도 컴포넌트를 사용하도록 변경했습니다. 지도 마커를 누르면 학교 주소와 직선거리가 표시됩니다. 입력 목록 또는 결과의 학교 이름을 누르면 해당 위치로 이동합니다. 지도 타일 서비스에는 표시 영역이 요청됩니다.

지도 출처: https://www.openstreetmap.org/copyright · 타일 정책: https://operations.osmfoundation.org/policies/tiles/ . 대규모 배포 시 적합한 타일 제공자를 선택하세요. Windows 네이티브 플러그인 빌드에는 Developer Mode의 심볼릭 링크 지원이 필요합니다.



지도 크기는 화면 높이에 따라 420~640px로 표시합니다. 출발지와 학교가 있으면 직선 연결선을 그리며, 최단거리는 주황색 굵은 선과 밝은 테두리로 강조합니다. 동일한 최단거리의 학교는 모두 강조됩니다. 학교 삭제·출발지 변경 시 다시 계산합니다. 연결선은 도로 경로가 아닙니다.

## 일반 장소 검색
학교뿐 아니라 기관·교육센터·상점·카페 등 카카오 장소 검색에 등록된 명칭을 검색합니다. 장소 주소를 비워 두고 이름을 입력하세요. 같은 이름이 많으면 지역명·지점명을 함께 입력하면 됩니다. 주소를 직접 입력하면 주소 검색을 우선 사용합니다. 검색 결과의 등록명·주소·좌표를 선택해 거리와 지도 연결선을 확인할 수 있습니다. 검색 결과는 카카오 등록 데이터에 따라 달라집니다.
